ArtistLab Third-Party Notices

Last updated: August 11, 2026

Platform frameworks

ArtistLab uses Apple platform frameworks for SwiftUI, SwiftData, photo picking, image processing, local storage, and sharing.

Color names and local assets

The app includes a bundled local color-name catalog and local visual texture assets used by Color Lab, Paint Lab, and palette presentation. These notices should be checked against the final app bundle before release.

Repository notice file

The repository also maintains docs/THIRD_PARTY_NOTICES.md. Review that file together with this public page before TestFlight or App Store distribution.
